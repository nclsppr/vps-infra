# Triage labels

The skills use five canonical triage roles. This table maps each role to its GitHub label.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an unattended agent. |
| `ready-for-human` | `ready-for-human` | A human must implement the issue. |
| `wontfix` | `wontfix` | The maintainers will not implement the issue. |

When a skill names a role, use the corresponding GitHub label from this table. Edit the GitHub label column if the repository adopts a different vocabulary.

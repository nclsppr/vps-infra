# Sécurité

Ce dépôt est public par conception. Il ne contient que de l’automatisation et
des valeurs non sensibles.

Ne publiez pas de vulnérabilité contenant une adresse d’hôte privée, une clé, un
jeton, un secret applicatif ou un extrait de données dans une issue publique.
Utilisez la fonctionnalité **Report a vulnerability** de l’onglet Security du
dépôt GitHub.

Tout secret commité par erreur doit être révoqué immédiatement. Supprimer le
fichier dans un commit ultérieur ne suffit pas.
